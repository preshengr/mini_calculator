# Mini Calculator App

A simple and responsive calculator built using HTML, CSS, and JavaScript. This project is perfect for beginners who are learning basic web development skills and want to understand DOM manipulation and event handling in JavaScript.

## Demo

You can check out a live demo of the Mini Calculator here: [Live Demo](#) *(Replace with actual link if hosted)*

---

## Features

- Basic arithmetic operations: Addition, Subtraction, Multiplication, Division
- Clear (`C`) and Delete (`⌫`) functions
- Responsive and mobile-friendly design
- Keyboard input support (optional enhancement)

---

## Technologies Used

- **HTML5** – Markup for calculator layout
- **CSS3** – Styling and responsive layout
- **JavaScript (ES6)** – Functionality and interactivity

## Getting Started

### Prerequisites

To run this project, you'll need a web browser. No additional setup is required.

### Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/mini_calculator_app.git
   ```
2. Navigate into the project directory:
   ```bash
   cd mini_calculator_app
   ```
3. Open `index.html` in your browser:
   - You can double-click the file or use a Live Server extension if using VSCode.

---

## Usage

1. Use the number and operator buttons to input your expression.
2. Click `=` to evaluate.
3. Use `C` to clear the input or `⌫` to delete the last digit.
